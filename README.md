# Studi_Kasus_3_Celsines Rante Tasak

Program Python ini dibuat untuk mengolah data nilai mahasiswa berdasarkan kriteria batas lulus.

## Penjelasan Singkat Kode
1. **Inisialisasi Data:** Menggunakan `tuple` untuk menyimpan batas nilai lulus (65, 100) dan `list` kosong untuk menampung nilai.
2. **Perulangan Input:** Menggunakan `while True` untuk menerima input nilai berulang kali sampai pengguna mengetik `selesai`.
3. **Konversi & Pengelompokan:** Mengubah input teks menjadi angka bulat (`int`) lalu membaginya ke dalam list `lulus` atau `remedi`.
4. **Penghapusan Nilai:** Meminta masukan nilai yang ingin dihapus, lalu menghapusnya dari seluruh list menggunakan metode `.remove()`.
5. **Output:** Tampilan akhir seluruh daftar nilai.
